# Exercicio 05

Código da questão:

```c
main()
{
    printf("Linguagem C");
    system("pause");
}
```

O código não compila certo em C ANSI. Faltam:

1. O include stdio.h, que é onde fica o printf.
2. O include stdlib.h, que é onde fica o system.
3. O int antes de main.
4. O return 0 no final da função.
